# ADR-0007：触控手势状态机与第二指回滚

- 状态：Proposed（架构评审）
- 日期：2026-11-05
- 相关：architecture.md §7、§16

## 背景

平板/手机上，单指既可能绘制，也可能想缩放/平移；双指手势与落笔会冲突。设计稿要求：单指绘制、双指缩放/平移、第二指落下回滚未完成笔画、手写笔优先；手机底栏 7 个工具（不含平移），双指平移。

## 决策

- 使用 Pointer Events + `touch-action: none` + pointer capture。
- 手势状态机：`idle → pending → draw | shape | pan | pinch`。
- 第二根手指按下时：
  1. 取消当前笔画事务并**回滚已落的豆子**；
  2. 进入 pinch，记录初始距离/中点/锚点格；
  3. 双指移动同时缩放 + 平移；
  4. 抬起一指回到 idle，不自动续画。
- 平移：
  - 平板/桌面工具栏保留“平移”工具；
  - 手机不设平移工具，使用双指平移（设计已确认）。
- 手写笔模式（设置开关）：
  - `pointerType === 'pen'` 绘制；
  - 手指只平移/缩放；
  - 默认关闭（手指可绘制）。
- 长按吸管：v1 不做（与落笔冲突）；吸管为独立工具。
- 滚轮/双击缩放；坐标换算考虑 CSS 缩放/DPR。

## 结果

**正面**

- 手势可预测；不会因为想缩放而误落一片豆子。
- 手机工具坞可完整容纳 7 个工具 + 当前色。
- 手写笔用户可避免手掌误触。

**负面**

- 第二指撤销当前笔画可能让用户意外（需要视觉/触觉反馈提示）。
- 需要真机测试不同浏览器/触控板。
- 无长按吸管，需要先切换工具。

## 备选方案

| 方案 | 不选原因 |
|---|---|
| 单指默认平移，绘制需切工具 | 高频绘制变慢 |
| 长按进入绘制/吸管 | 与落笔冲突，误触多 |
| 手势库 | 包体/行为不可控；自研状态机更贴合 |
| 手机保留平移工具 | 底栏空间不足，7 工具+当前色已满 |

## 说明

- 回滚是“取消未完成笔画”，不是撤销上一条历史；撤销仍由 History 管理。
- 触控板：滚轮缩放；双指触控板由浏览器映射为 wheel/pointer，按实际测试调整。
- 真机验收必须覆盖 iPad Safari、Android Chrome。
