# ADR-0004：A4 PDF 使用 Canvas 光栅页 + jsPDF

- 状态：Proposed（架构评审）
- 日期：2026-11-05
- 相关：architecture.md §9、§11

## 背景

导出需要 A4 分页、中文标题/色号、图例、页码、镜像、1:1 实物尺寸。纯矢量 PDF 需要嵌入中文字体（Noto Sans SC 子集通常数 MB，jsPDF 字体嵌入流程复杂）；浏览器打印 HTML 的纸型/边距不可控，无法保证 1:1 与分页。

## 决策

- 页面排版用 Canvas 2D 渲染（浏览器系统字体），每页转 PNG，再用 jsPDF 逐页 `addImage` 组装 A4 PDF。
- 默认 **200 DPI**；300 DPI 作为后续/内部高级项（v1 导出面板不新增控件）；逐页创建/释放 Canvas。
- 分页由纯函数 `core/pagination.ts` 计算；支持 fit / 1:1 实物 / 自定义每格 mm、重叠 0–3、图例页。
- jsPDF 动态 import，避免进入首屏 bundle。
- 导出进度按页显示；页面渲染之间让出一帧，避免长时间阻塞。
- 导出图片仅用于 PDF；原始工程数据不变；镜像只影响绘制。

## 结果

**正面**

- 中文/色号无字体嵌入问题；视觉与 Canvas 图纸一致。
- 分页/镜像/1:1 完全可控；纯前端。
- 实现简单，跨浏览器一致（都是 Canvas 渲染）。

**负面**

- PDF 内是图片，文字不可选中/搜索；文件更大。
- 内存峰值取决于页数/DPI；需要逐页释放与页数上限。
- 300 DPI 大图在 iOS 上有内存风险；默认 200 DPI。

## 备选方案

| 方案 | 不选原因 |
|---|---|
| jsPDF 矢量 + 中文字体嵌入 | 字体子集大/流程复杂；多页色号排版仍要大量代码 |
| HTML + window.print() | 浏览器边距/缩放不可控；无法可靠分页/1:1 |
| 服务端 PDF | 无后端；离线不可用 |
| PDFKit/WASM | 包体/兼容/字体问题；收益不足 |

## 说明

- 若未来需要可选中文字，再评估嵌入 CJK 字体或生成双版本 PDF。
- 页数很多时提示用户；后续可加“只导出图纸页/图例页”选项。
- 图像编码优先 PNG（平色/文字清晰）；如文件过大再评估 JPEG/压缩策略。
