## 1. 产品概述

**拼豆工坊**是一款平板/手机触控优先的中文拼豆制图工具，完成「导入图片或空白画布 → 真实色号像素图纸 → 逐格编辑 → 用量统计 → 可打印图纸」的闭环。

**核心目标**

- 让玩家把一张图片快速变成**能直接照着拼、能按色号买豆**的图纸。
- 在平板上单手/双手都能舒适操作；手机能完成查看、修改、导出的轻量工作。
- 把「色卡」作为产品的主角：真实 MARD 色号、色块、用量一目了然。
- 图纸优先：编辑区尽可能大，工具栏和面板克制，不抢图纸的注意力。

**设计原则**

1. **色卡是主角**：界面用暖纸色和低饱和色，把高饱和留给豆子颜色。
2. **图纸优先**：编辑器的画布占据最大面积；面板可收起，不遮挡操作。
3. **触控友好**：主要触控目标 ≥44px；单指绘制、双指缩放/平移；危险操作二次确认。
4. **手作温度**：纸感底色、圆形豆子、圆角卡片、轻微阴影；不追求冷冰冰的工具感。
5. **状态清晰**：当前色、当前工具、用量、保存状态、撤销/重做始终可见或一键可达。

## 2. 目标用户与典型场景

- **主要用户**：使用 2.6mm 融合豆/蜜豆的拼豆玩家，手头有一盒 226 色套装或 MARD 色卡。
- **典型场景**
  - 在平板上导入一张喜欢的图片，转换成 52×52 图纸，逐格修掉杂色，导出 A4 打印。
  - 从零画一个钥匙扣图案，按用量清单备豆。
  - 在手机上打开已保存的图纸，快速改几颗豆子，把 PNG 分享给朋友。
  - 对照实物色卡，只启用自己拥有的颜色，避免图片转换出一堆买不到的色号。

## 4. 核心用户流程

### 流程 A：空白图纸 → 绘制 → 导出

1. 首页点「新建图纸」。
2. 选择豆径（默认 2.6mm）、板型（默认 52×52，约 13.5cm）或自定义尺寸。
3. 创建后进入编辑器；空画布显示引导卡片。
4. 在色板选色，点按/拖动画布落豆；可用填充、形状、吸管、对称、撤销。
5. 打开「用量统计」确认总颗数与色号清单。
6. 打开「导出图纸」，选择 PNG / A4 PDF / CSV，导出或分享。

### 流程 B：图片 → 图纸

1. 首页「从图片开始」或在编辑器「更多 → 从图片导入」。
2. 选图（原型用示例图）→ 裁剪（锁定 52×52 比例）→ 调色（亮度/对比度/饱和度、背景移除、最多颜色数、抖动、我的色卡）→ 原图/图纸对比 → 应用。
3. 应用时可选择「新建工程」或「替换当前画布」；替换后可通过撤销恢复。
4. 进入编辑器继续逐格修改。

### 流程 C：我的色卡

1. 色板 → 我的色卡。
2. 选择 221 常用 / 291 全色 / 自定义，或按系列全选。
3. 也可粘贴/导入色号清单（支持逗号、空格、换行），精确匹配手头的 226 色套装。
4. 保存后，图片转换只使用启用色号；色板「我的」标签同步更新。

### 流程 D：工程管理

- 首页工程卡片 → 更多 → 打开 / 复制一份 / 重命名 / 删除。
- 删除前二次确认；复制生成「原名称 副本」。

## 5. 屏幕清单与规格

### 5.1 首页

**目的**：快速回到最近工程，或开始新图纸。

**布局（宽屏）**

- 顶部：品牌标识 + 从图片开始 / 新建图纸。
- Hero：大标题「把灵感，拼成一颗颗豆子。」+ 副标题 + 右侧装饰豆子。
- 「最近工程」：3 列工程卡片；平板 2 列；手机 1 列。
- 卡片：缩略图（4:3 / 手机 16:10）、尺寸与豆径徽标、名称、成品厘米、色数、板数、总颗数、更新时间、打开箭头、更多按钮。
- 底部：色值参考与本地保存提示。

**状态**

- 正常：4 个示例工程。
- 空状态（设计要求，原型见设计系统页）：豆子插画 +「还没有图纸」+ 新建 / 从图片开始。
- 加载/错误：骨架与错误条，原型在设计系统页展示。

**交互**

- 点卡片任意位置打开编辑器；点更多打开工程菜单（不触发打开）。
- 手机端更多按钮始终可见；桌面端悬停显示。
- 键盘 Enter/Space 打开卡片。

### 5.2 新建工程

**目的**：用最少的输入确定画布。

**字段**

- 图纸名称（默认「未命名图纸」）。
- 豆子规格：2.6mm 小豆 / 5mm 中豆。
- 板型预设：
  - 2.6mm：52×52（默认，约 13.5cm）、50×50、78×78、104×104。
  - 5mm：29×29（约 14.5cm）、57×57。
- 自定义宽度/高度（1–300 格）+ 交换宽高。
- 预览摘要：尺寸、成品厘米、板数、豆径。
- 色卡行：MARD · 我的色卡（N 色）+ 调整。

**交互**

- 选预设后尺寸联动；手动改宽高自动切到「自定义」。
- 手机为底部 Sheet（近全高、可拖拽关闭）；桌面为居中 Dialog。
- 创建后进入空画布编辑器，显示落豆引导。

### 5.3 编辑器

**宽屏布局**

```
顶栏（62px）：返回 · 名称/尺寸/已保存 · 撤销/重做 · 统计 · 导出 · 更多
左工具栏（64px） + 画布 + 右侧色板（318px）
底栏（32px）：坐标 · 总颗数 · 色数 · 豆径/尺寸/成品 · 缩放
```

**平板布局（600–899）**

- 顶栏同宽屏，但隐藏固定色板，增加「色板」按钮（右侧抽屉）。
- 左工具栏 + 画布 + 底栏。

**手机布局（<600）**

```
顶栏（54px）：返回 · 名称/尺寸 · 撤销 · 重做 · 色板 · 更多
画布 + 左上尺寸浮标 + 右上用量浮标 + 右下缩放药丸
底部工具坞（65px）：7 个绘制工具 + 当前色圆豆（点按打开色板）
```

- 不在手机底部放平移工具；平移使用双指手势。椭圆等 7 个工具全部完整显示。
- 色板 / 统计 / 导出 / 设置 / 我的色卡均为底部 Sheet。
- 当前色圆豆同时承担「当前颜色」与「打开色板」两个作用。
- 手机顶栏保留名称/尺寸，隐藏「已保存」文字（自动保存持续生效）；宽屏/平板显示绿点「已保存」。

**画布**

- 图纸（artboard）居中，标尺贴着图纸的上边和左边绘制，而不是固定在画布边缘。
- 左上角有珊瑚色小豆标记；标尺每 5/10 格显示坐标（根据缩放）。
- 网格：每格线、每 5 格、每 10 格逐级加深；板边界（如 52 格）更粗；104×104 画布显示四块板的十字分隔。
- 空格显示极淡的钉点（高缩放时）。
- 格内色号：缩放 ≥20px/格 时按开关显示；根据底色自动选深/浅文字。
- 缩放范围 25%–1000%（以适配屏幕为 100%）；滚轮/双指/按钮/双击缩放；「适应屏幕」复位。
- 空画布：居中引导卡片 +「从图片开始」。

**工具**

- 画笔、橡皮、填充（4 连通）、吸管、直线、矩形、椭圆、平移。
- 笔刷 1×1 / 2×2 / 3×3（工具栏「笔刷」循环）。
- 对称：关 / 水平 / 垂直 / 四向（工具栏「对称」循环）。
- 画笔/橡皮支持拖动画线；形状工具显示半透明预览，抬起后落豆。
- 撤销/重做 ≥40 步；第二根手指落下时回滚未完成笔画并进入缩放/平移。

**状态栏**

- 光标坐标（悬停时）、总颗数、色数、当前色（可选）、豆径/尺寸/成品厘米、缩放百分比。
- 手机端以左上尺寸浮标 + 右上用量浮标替代。

### 5.4 色板

**宽屏**：固定右侧面板，宽 318px。  
**平板/手机**：右侧抽屉 / 底部 Sheet。

**结构**

1. 标题 +「我的色卡」入口。
2. 当前色卡：圆豆、色号、颜色名、当前用量颗数。
3. 标签：已用 N / 全部 N / 我的 N。
4. 搜索：色号或颜色名。
5. 系列筛选：全部 / A–H / 其他。
6. 色块网格：4 列；圆形豆子 + 色号；已用角标显示颗数；选中态珊瑚描边。
7. 底部说明：屏幕色值仅供参考。

**空状态**

- 已用为 0：「还没有用过的颜色 / 切到「全部」，选一个颜色开始落豆」。
- 搜索无结果：「没有匹配的色号」。

**交互**

- 点色块即选中；若当前是橡皮，自动切回画笔。
- 手机/平板选择后自动关闭色板 Sheet，回到画布。
- 已用列表按用量从高到低排序。

### 5.5 我的色卡

**目的**：把软件色卡对齐到用户实际拥有的豆子。

- 顶部：大号「已启用 221 / 291（默认 221 常用）」+ 说明。
- 预设：221 常用 / 291 全色 / 自定义。
- 系列：A–H / 其他，点击整组启用或取消；全部启用时显示对勾。
- 粘贴色号清单：文本框 +「解析并启用」；支持逗号、空格、换行；兼容 A1 / A01 写法。
- 色号列表：2 列（手机）/ 3 列（平板/宽屏），每项包含圆豆、色号、名称、勾选。
- 底部：取消 / 保存我的色卡。

**规则**

- 保存后图片转换只使用启用色号；编辑器仍可查看全部色号。
- 原型已内置完整 MARD 291 色（221 常用 + 70 特殊效果），默认启用 221 常用；可切 291 全色，或粘贴 226 色套装清单。
- 屏幕 HEX 为参考值，支持后续校准。

### 5.6 图片转图纸向导

**步骤指示**：选图 → 裁剪 → 调色 → 预览 → 应用。  
**布局**：宽屏/平板双列，手机单列；底部固定操作条（上一步 / 下一步 / 应用图纸），手机隐藏提示文案、主按钮占满剩余宽度。

**Step 1 选图**

- 大号拖放/上传区域；原型点击提示使用示例图。
- 3 张示例图片卡片：草莓、小猫、小花；选中显示珊瑚边框 + 对勾。

**Step 2 裁剪**

- 方形裁剪框（与 52×52 图纸同比例），宽屏 54vh 上限、手机 46vh；图片填充/适应、缩放 100–200%、旋转 90°。
- 三分线、四角标记、暗角；裁剪预览徽标。
- 右侧/下方控制卡与提示。

**Step 3 调色**

- 色彩：亮度 / 对比度 / 饱和度滑杆（带数值）。
- 背景：自动移除浅色背景开关 + 容差；关闭时容差滑杆禁用。
- 色卡与颜色：最多颜色数步进器（4–48）、Floyd–Steinberg 抖动开关、使用色卡行（我的色卡 N 色 + 调整）。
- 预览：方形图纸、实时颗数/色数；处理时显示「处理中」小药丸。
- 手机：预览在控制区**上方并吸顶**，滚动调参时始终可见。

**Step 4 预览**

- 正方形前后对比：左侧原图（豆子照片质感），右侧图纸（清晰方格），中间可拖动分割线；5%–95% 限制。
- 标签「原图」「图纸」；底部提示拖动对比。

**Step 5 应用**

- 缩略图（宽屏/平板；手机隐藏，以摘要卡替代）+ 摘要卡：总颗数、颜色数、画布格数。
- 图纸名称（新建时可编辑）。
- 应用方式（从编辑器进入时）：替换当前画布 / 新建工程；显示当前画布尺寸变化警告。
- 应用后仍可撤销（替换时）。

### 5.7 用量统计

- 统计卡：总用量（珊瑚强调）、色号数量、按板估算块数。
- 列表：按用量排序；圆豆、色号、名称、用量条、颗数、占比。
- 底部：导出用量 CSV。
- 空状态：还没有落下的豆子。

### 5.8 导出图纸

**格式标签**：PNG 图纸 / A4 PDF / 用量 CSV。

**PNG**

- 预览：图纸 + 图例点。
- 每格像素：8 / 16 / 24 / 32。
- 开关：格内色号、行列坐标、图例与用量。
- 文件名：`{工程名}_图纸.png`。
- 说明：分享和电子查看用 PNG，打印用 PDF。

**A4 PDF**

- 预览：A4 页面缩略（含标题、图纸、图例、页码）。
- 每格尺寸：适配页面 / 1:1 实物 / 自定义。
- 重叠边：0–3 格。
- 打印选项：镜像（熨烫方向）、格内色号、图例页。
- 摘要：`X×Y 拼版 · 共 N 页（含图例页） · A4`。
- 文件名：`{工程名}_A4.pdf`。
- 说明：自动分页、全局行列号、镜像不影响工程数据。

**CSV**

- 预览表：色号、名称、HEX、颗数、占比。
- 文件：UTF-8 BOM，Excel 直接打开。
- 文件名：`{工程名}_用量.csv`。

**交互**

- 导出按钮显示「生成中…」并禁用，完成后 Toast 提示；原型为演示，不产生真实文件。
- 手机端提供系统分享入口（原型提示）。

### 5.9 画布设置

- 画布尺寸：宽/高输入 + 九宫格锚点（左上/上/右上/左/中/右/左下/下/右下）+ 应用尺寸；缩小会裁剪，可撤销。
- 整图变换：水平翻转、垂直翻转、左转 90°、右转 90°。
- 整图替换颜色：从/替换为两条已用色列表 + 预览（A01 → F04）+ 应用替换；同色禁用。
- 危险区：清空画布（二次确认）。
- 手机为底部 Sheet，桌面为 640px Dialog。

### 5.10 工程菜单 / 重命名 / 确认

- 工程菜单：打开图纸、复制一份、重命名、删除图纸（危险色）。
- 重命名：名称输入 + 取消/保存。
- 确认：标题 + 说明 + 取消/危险确认；清除/删除均二次确认。

### 5.11 设计系统页

评审辅助页，包含：

- 色彩 token（12 个核心色）。
- MARD 色板（291 色，默认 221 常用）。
- 字体层级。
- 按钮、工具按钮、豆子色块状态（普通/选中/已用/未启用/浅色描边）。
- 表单控件（搜索、滑杆、开关、步进器、分段、筛选 chip）。
- 反馈状态（Toast、空状态、骨架、错误条）。
- Sheet 结构解剖（Grabber / Header / Body / Footer）。
- 图标集（51 个 24×24 图标）。
- 响应式断点示意与圆角/动效说明。

## 6. 设计 Token

### 6.1 色彩

| Token | 值 | 用途 |
|---|---|---|
| 纸张 | `#F6F1E7` | 应用底色 |
| 卡片 | `#FFFDF7` | 面板、卡片、弹层 |
| 浅底 | `#F8F2E7` | 输入框、次级容器、标尺 |
| 墨色 | `#2A241E` | 主文字 |
| 次级文字 | `#7B7164` | 说明、元信息 |
| 描边 | `#E6DCCB` | 分割线、卡片边框 |
| 珊瑚 | `#D95D4E` | 主操作、选中、当前色强调 |
| 深青 | `#2F6B62` | 选中态、正向状态、滑杆 |
| 提示金 | `#C9933F` | 提示、注意事项 |
| 危险 | `#B83B32` | 删除、清空 |
| 成功 | `#4F7A52` | 已保存、成功 |
| 夜色 | `#241F1A` | 评审栏、Toast |

**使用规则**

- 珊瑚只用于主操作和当前状态；不要大面积铺。
- 豆子色块使用真实色值，界面其余部分保持低饱和。
- 浅色豆子（白/米白）必须有 1px 内描边，避免在纸色上消失。
- 深色豆子上的文字使用白色或浅色，浅色豆子使用墨色。

### 6.2 字体

- 字族：`PingFang SC / Noto Sans SC / Hiragino Sans GB / Microsoft YaHei / system-ui`。
- 数字：`font-variant-numeric: tabular-nums`（颗数、坐标、百分比、尺寸）。
- 层级：
  - Display 46：首页 Hero（`clamp(30px, 4.4vw, 46px)`）。
  - Display 32：设计系统展示。
  - Title 18–20：页面标题、Sheet 标题（15–16 为主）。
  - Body 13–14：正文、输入。
  - Caption 10–11：说明、元信息。
  - Micro 8–9：色号、角标、标签。
- 行高：标题 1.15–1.25；正文 1.55–1.75。
- 字重：400/500/600/650/700/750。

### 6.3 间距与圆角

- 间距：4 / 8 / 12 / 16 / 24 / 32 / 40；页面边距 16（手机）/ 28（平板）/ 54（宽屏）。
- 圆角：8 小控件、10–12 按钮/输入、14–16 卡片、20 大卡片、24–28 Sheet/设备、999 胶囊。
- 触控目标：主要操作 ≥44px；工具栏 44–48px；豆子色块按钮 60px 高；辅助图标 ≥32px。

### 6.4 阴影与层级

- `shadow-sm`：卡片、输入、浮标。
- `shadow-md`：悬浮卡片、缩放药丸、色板面板。
- `shadow-lg`：Sheet、Dialog、Toast、设备外框。
- 层级：画布 < 浮标 4 < 工具栏/顶栏 < 遮罩 60 < Sheet 61 < Toast 300 < 评审栏 500。

### 6.5 动效

- 120–180ms，`cubic-bezier(.2,.8,.2,1)`。
- Sheet 上滑/右滑 180–260ms；菜单/弹层 160–200ms；按钮按压 1px。
- `prefers-reduced-motion: reduce` 时全部动效关闭（含豆子漂浮）。

### 6.6 图标

- 24×24 viewBox，1.8px 线宽，圆角端点；内联 SVG，无外网依赖。
- 图标风格：线性、几何、克制；只有「更多」等少数使用填充圆点。
- 图标按钮必须有 `aria-label`；隐藏文字的按钮在手机端保留可访问名称。

## 10. 状态与反馈

- **空**：首页无工程、画布无豆、已用色为 0、统计无数据、搜索无结果。
- **加载**：图片转换时显示「处理中」药丸；导出按钮「生成中…」并禁用。
- **错误**：图片过小/格式不支持；剪贴板无有效色号；同色替换禁用并提示。
- **警告**：替换画布会改变尺寸；1:1 PDF 色号字号较小；屏幕色值仅供参考。
- **成功**：创建、复制、重命名、删除、保存我的色卡、应用图纸、导出完成 → Toast。
- **保存状态**：编辑器顶栏绿点「已保存」；原型模拟自动保存。
- **危险操作**：清空画布、删除图纸 → 二次确认。

## 11. 数据与内容规范

### 11.1 色卡

- 原型已内置完整 **MARD 291 色**（221 常用 + 70 特殊效果：珠光/温变/果冻/透明白/夜光/光变）。
- 默认启用 **221 常用色**；用户可通过「我的色卡」切换 291 全色、自定义勾选，或粘贴 226 色套装清单。
- 所有 HEX 为公开色号表的屏幕参考值，不替代实物比对；界面需持续提示。
- 色号格式：字母 + 两位数字（如 A01、F04、H02）；解析时兼容 A1 → A01。

### 11.2 尺寸与板型

- 2.6mm 豆：默认板 52×52（约 13.5cm）；另有 50×50、78×78、104×104；自定义 1–300 格。
- 5mm 豆：29×29（14.5cm）、57×57（28.5cm）。
- 板数估算：`ceil(宽 / 板宽) × ceil(高 / 板高)`。
- 成品尺寸：`格数 × 豆径`，界面以 cm 保留一位小数。

### 11.3 文案

- 用「颗」计量豆子，用「格」计量画布，用「色」计量色号，用「块板」计量底板。
- 数字使用千分位（1,018 颗）；百分比 <1% 显示 `<1%`。
- 语气：简短、友好、可执行；避免技术术语（如「量化」「OKLab」不出现在用户界面）。
- 文件命名：`{工程名}_图纸.png`、`{工程名}_A4.pdf`、`{工程名}_用量.csv`。

### 11.4 本地数据与自动保存

- **本地优先**：不登录、不上传；工程与我的色卡都保存在当前设备。
- **保存内容**：工程列表（名称、尺寸、豆径、板型、cells、更新时间）、我的色卡启用集合。
- **原型**：使用 `localStorage`（key `pindou-demo-v1`）演示；编辑后约 200ms 防抖写入；评审栏「重置」会清空本地数据并恢复示例。
- **正式版**：IndexedDB 存储 + schemaVersion + 迁移；自动保存 800ms 防抖 + 页面隐藏时保存；启动恢复最近工程。
- **备份**：正式版提供 `.pindou.json` 工程导出/导入；界面提示「本地存储可能被清理，重要图纸请导出备份」。
- **不做云同步**：账号、多人协作、跨设备同步不在 v1 范围。

## 12. 无障碍

- 主要触控目标 ≥44px；色块按钮 60px 高；工具 44–48px。
- 图标按钮提供 `aria-label`；隐藏文字的按钮保留可访问名称。
- 颜色不是唯一信息：色块同时显示色号、用量角标、名称；统计列表同时显示数字与百分比。
- 对比度：墨色/纸色、珊瑚/白、青色/白均满足 AA（小字号文字避免用浅金）。
- 可见焦点：`focus-visible` 2px 青色描边。
- 尊重 `prefers-reduced-motion`。
- Canvas 有 `role="application"` 与操作说明；图纸的用量可通过统计列表以文本形式获取。
- Sheet/Dialog 使用 `role="dialog"`、`aria-modal`；关闭按钮可聚焦。

## 14. 评审与使用说明

**打开方式**

- 直接双击 `design/prototype/index.html`（无构建、无外网依赖）。
- 或在 `design/prototype/` 下起本地静态服务器后访问。

**评审工具**

- 顶部评审栏：自适应 / 平板横屏 1024×768 / 平板竖屏 768×1024 / 手机 390×844。
- 「设计系统」查看 token、组件与状态。
- 「重置」恢复示例数据。

**建议评审路径**

1. 首页 → 打开草莓图纸 → 改色 → 落豆 → 撤销 → 统计 → 导出 PNG/PDF/CSV。
2. 首页 → 新建图纸 → 104×104 → 空画布 → 落豆。
3. 编辑器 → 更多 → 从图片导入 → 5 步 → 替换当前画布 → 撤销。
4. 色板 → 我的色卡 → 关掉一个色号 → 粘贴色号 → 保存。
5. 切换手机尺寸 → 编辑器 → 底部工具坞 → 色板 Sheet → 设置 Sheet → 导出 Sheet。
6. 切换平板竖屏 → 色板抽屉 → 画布设置 → 用量统计。
7. 修改我的色卡或画布后刷新页面，确认工程与色卡仍在；点评审栏「重置」清空本地数据。
8. 设计系统页检查 token、组件、图标与状态。

**阶段 1 验收标准**

- 三种预览尺寸下所有主要屏幕可达，无横向溢出，Sheet 不被裁切。
- 主要流程可点击走通；画布可落豆/擦除/撤销；向导可调参、对比、应用。
- 触控目标符合规范；色板在 390px 宽下可准确点选。
- 设计 token 与组件清单可直接映射到阶段 3 实现。
- 本文档与原型行为一致。

## 15. 范围外与待确认

**本版不做**

- 账号/云同步、多人协作、图层、选区/移动工具、分板拼接图、逐豆完成打卡、参考底图描图、OCR 色卡、库存采购。
- 真实图片转换、真实 PDF/PNG/CSV 导出、真实持久化（阶段 3）。
- 长按吸管、手写笔压感、惯性滚动等增强手势（阶段 3 评估）。

**已确认 / 架构阶段处理**

- 默认色卡：MARD 221 常用；「我的色卡」默认 221，可切 291 全色、自定义或粘贴 226 清单。
